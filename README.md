# Камертон

Музыкальный плеер для Android: единая библиотека, плеер, импорт плейлистов и персональная волна.
Работает без сервера, все данные хранятся на телефоне.

## Как получить APK

APK собирается на серверах GitHub: **[пошаговая инструкция для телефона](docs/BUILD_APK.md)**.
Готовый файл появляется в разделе Artifacts запуска и устанавливается без настройки подписи.

## Первый запуск

Сразу работают Audius, Internet Archive, Radio Browser и файлы на телефоне.
Jamendo требует бесплатный Client ID, свой сервер настраивается в разделе **Профиль → Источники музыки**.
Подробности по каждому сервису: [docs/SOURCES.md](docs/SOURCES.md).

## Что реализовано

- Воспроизведение внутри приложения: локальные файлы, Subsonic/OpenSubsonic, Audius, Jamendo, Internet Archive, Radio Browser.
- Фон, экран блокировки, кнопки наушников, очередь, повтор, перемешивание, таймер сна, плавные переходы, восстановление после перезапуска.
- Волна, «Удиви меня», открытия дня, похожие, радио по песне, умный DJ, музыкальный портрет, общие лайки, умная очистка, умные плейлисты, новые релизы.
- Импорт текстом, файлами CSV/JSON/M3U/XSPF, по ссылке и из подключённых сервисов. Сопоставление через ISRC, MusicBrainz, название, исполнителя и длительность. Экспорт плейлистов.
- Оригинал важнее цензурированной версии. Неизвестная версия подписывается как неизвестная.
- Тексты из тегов, с вашего сервера и из .lrc-файлов. Клипы в видимом плеере YouTube.

Как я понял функции, для которых не нашлось отдельного описания:
**умный DJ** переставляет очередь по жанрам, темпу и эпохе и подписывает переходы;
**общие лайки** работают через файл-карточку вкуса, без сервера.

## Ограничения

- Яндекс Музыка, VK Музыка и Deezer: только переход в сервис и перенос плейлиста по названиям.
- Spotify: вход и импорт своих плейлистов. Нужны свой Client ID и Premium у владельца. Управление приложением Spotify (App Remote) не включено.
- Apple Music, SoundCloud, TIDAL: архитектура и описание готовы, подключение не включено. Нужны платные аккаунты или сервер.
- Плавный переход сделан затуханием. Настоящего наложения двух треков нет.
- Звук каталога не анализируется: темп и настроение берутся только из данных источника.

## Что проверено, а что нет

Проверено автоматически:

- проверка типов TypeScript;
- логические тесты: версии, сопоставление, база SQLite, плеер, рекомендации, импорт, адаптеры;
- чтение тегов из настоящих файлов MP3, FLAC, Opus и M4A;
- сборка Android-бандла Hermes и генерация Android-проекта;
- логика workflow и скрипты проверки APK на тестовых данных;
- сквозной сценарий в браузере на веб-сборке с подставными ответами сервисов.

Форматы ответов Audius и Internet Archive сверены с их живыми API, Jamendo и OpenSubsonic с документацией.

**Сборка APK и запуск на эмуляторе считаются проверенными только по результату GitHub Actions.**
**Не проверено на настоящем телефоне:** экран блокировки, Bluetooth, защищённое хранилище, вход в Spotify, плеер YouTube.
**Не проверено на настоящих серверах:** запросы приложения к Jamendo, Radio Browser, MusicBrainz, ListenBrainz, Navidrome и Spotify.
Доступность зарубежных сервисов из России нужно проверить на телефоне.

## Для разработки

```
npm ci
npm test
npm run typecheck
npx expo run:android
```

Код: `app` экраны, `src/sources` адаптеры, `src/player` плеер, `src/reco` рекомендации, `src/import` импорт, `src/db` база.
Новый источник: файл адаптера и одна строка в `src/sources/registry.ts`.
