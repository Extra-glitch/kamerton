# Камертон

Музыкальный плеер для Android: единая библиотека, плеер, импорт плейлистов и персональная волна.
Работает без сервера, все данные хранятся на телефоне.

## Как получить APK

APK собирается на серверах GitHub: **[пошаговая инструкция для телефона](docs/BUILD_APK.md)**.
Готовый файл появляется в разделе Artifacts запуска и устанавливается без настройки подписи.

## Первый запуск

Без настройки работают: поиск по каталогам Deezer и Apple Music, файлы на телефоне, Audius, Internet Archive, интернет-радио.
Чтобы слушать найденное целиком, подключите в **Профиль → Источники музыки**:

- **YouTube** — бесплатный ключ YouTube Data API. Поиск песен и клипов, прослушивание целиком во встроенном плеере YouTube (в России нужен VPN, в фоне не играет). С ним и песни из каталогов Deezer и Apple играют целиком: при нажатии приложение находит их полную версию на YouTube (каверы, ремиксы и караоке отсекаются) и запоминает её.
- **SoundCloud** — ключ API (выдаётся владельцам подписки Artist Pro). Поиск и прослушивание целиком прямо в плеере Камертона, в том числе в фоне (в России нужен VPN).

Как получить ключи: [docs/SOURCES.md](docs/SOURCES.md). Что отвечает каждый сервис на поиск: **Профиль → Диагностика источников**.

## Что реализовано

- Воспроизведение внутри приложения: локальные файлы, Subsonic/OpenSubsonic, Audius, Jamendo, Internet Archive, Radio Browser.
- Фон, экран блокировки, кнопки наушников, очередь, повтор, перемешивание, таймер сна, плавные переходы, восстановление после перезапуска.
- Волна, «Удиви меня», открытия дня, похожие, радио по песне, умный DJ, музыкальный портрет, общие лайки, умная очистка, умные плейлисты, новые релизы.
- Импорт текстом, файлами CSV/JSON/M3U/XSPF, по ссылке и из подключённых сервисов. Сопоставление через ISRC, MusicBrainz, название, исполнителя и длительность. Экспорт плейлистов.
- Оригинал важнее цензурированной версии. Неизвестная версия подписывается как неизвестная.
- Тексты из тегов, с вашего сервера и из .lrc-файлов. Клипы в видимом плеере YouTube.
- Единый поиск (Multi-Source Search): Deezer, Apple Music, YouTube, SoundCloud, Spotify, файлы на телефоне, свой сервер, Audius и Jamendo опрашиваются одновременно, результаты появляются по мере ответов, одинаковые песни объединяются. «Архив» и «Радио» — отдельные разделы.
- Варианты написания: кириллица, латиница, транслитерация и псевдонимы исполнителей из MusicBrainz («Моргенштерн» = MORGENSHTERN, «Дэд Блонд» = DEAD BLONDE).
- У каждой песни видно, где она найдена и как играет: целиком, на YouTube, фрагмент, по подписке, в другом приложении, закрыто в регионе.
- Перезаливы, каверы и ремиксы ниже оригинала; случайные совпадения в блоке «Похожие названия».
- Диагностика источников: кто участвовал в поиске, кто ответил, сколько нашёл, почему песни нет.
- Перенос из Яндекс Музыки: разбор текста, скопированного со страницы плейлиста, архива данных Яндекса (JSON/CSV) и CSV сервисов переноса. Предпросмотр перед сопоставлением, быстрый режим для сотен песен.
- Оформление: стеклянные панели с настоящим размытием на Android 12+, фон и акцент из цветов обложки. Фоновые анимации убраны: они тормозили на телефонах.

Как я понял функции, для которых не нашлось отдельного описания:
**умный DJ** переставляет очередь по жанрам, темпу и эпохе и подписывает переходы;
**общие лайки** работают через файл-карточку вкуса, без сервера.

## Ограничения

- Яндекс Музыка, VK Музыка, Звук и МТС Музыка не дают сторонним приложениям API для поиска и воспроизведения. Есть только неофициальные библиотеки, которые используют закрытый API их приложений: это запрещено правилами проекта и, по сообщениям пользователей, приводит к блокировке аккаунта. Поэтому — только переход в сервис и перенос плейлиста по названиям.
- Deezer: поиск и фрагменты по 30 секунд. Полные треки Deezer сторонним приложениям не отдаёт.
- YouTube: только видимый официальный плеер, без фона и скачивания; около 100 поисков в сутки на бесплатный ключ (повторы берутся из памяти).
- SoundCloud: ключ API только для подписки Artist Pro; в России нужен VPN.
- Apple Music: поиск по каталогу работает без ключа, но внутри приложения не играет. Для воспроизведения нужна библиотека MusicKit для Android, платный аккаунт разработчика Apple (99 долларов в год) и подписка Apple Music. Сейчас песня открывается в приложении Apple Music.
- Spotify: вход, импорт и поиск. Нужны свой Client ID и Premium у владельца. Управление приложением Spotify (App Remote) не включено. В России Spotify не работает.
- Плавный переход сделан затуханием. Настоящего наложения двух треков нет.

## Что проверено, а что нет

Проверяется при каждой сборке в GitHub Actions:

- типы TypeScript и логические тесты: версии, сопоставление, база, плеер, рекомендации, импорт, адаптеры;
- чтение тегов из настоящих файлов MP3, FLAC, Opus и M4A;
- сборка Debug APK, наличие кода приложения и библиотек, действительность подписи;
- запуск на эмуляторе Android 14 (x86_64) без компьютера и сервера разработки;
- поиск аудио на устройстве и чтение тегов, воспроизведение файла, работа в фоне;
- медиакнопки «следующий», пауза и воспроизведение;
- замена очереди: звучит только один трек;
- отсутствие падений и ошибок JavaScript.

Волна из интернета, поиск в каталоге, фрагмент и ссылка SoundCloud тоже проверяются на эмуляторе, но сбой внешнего сервиса считается предупреждением.

Отдельная проверка **Live search check** при каждом изменении кода отправляет настоящие запросы («Моргенштерн», «Дэд Блонд», «DEAD BLONDE», «Земфира», «The Weeknd», «Blinding Lights» и другие) в Deezer, Apple Music, MusicBrainz и Audius и выводит таблицу в сводку запуска. YouTube и SoundCloud проверяются там же, если добавить секреты репозитория `YT_API_KEY`, `SC_CLIENT_ID` и `SC_CLIENT_SECRET`.

Последняя проверенная сборка: №16 (19.11.2026). На эмуляторе в сети GitHub поиск «Morgenshtern» нашёл 55 треков за 1,3 секунды,
открылась страница исполнителя, заиграл фрагмент из каталога, по ссылке открылся плеер SoundCloud.

**Не проверено на настоящем телефоне:** работа ARM-версии, вид экрана блокировки, настоящие Bluetooth-наушники, клипы YouTube, плеер SoundCloud через VPN, вход в Spotify, работа Deezer из России без VPN.
**Не проверено на настоящих аккаунтах и серверах:** Jamendo, Navidrome/Subsonic, Spotify.
Эмулятор работает в сети GitHub, поэтому доступность сервисов из России нужно проверить на телефоне.

## Для разработки

```
npm ci
npm test
npm run typecheck
npx expo run:android
```

Код: `app` экраны, `src/sources` адаптеры, `src/player` плеер, `src/reco` рекомендации, `src/import` импорт, `src/db` база.
Новый источник: файл адаптера и одна строка в `src/sources/registry.ts`.
