# Источники музыки

Файл создан автоматически из описаний адаптеров (`npm run docs`).

## На телефоне

Ваша музыка на телефоне: MP3, FLAC, Opus, M4A и другие форматы, которые поддерживает Android.

- Категория: На этом телефоне
- Воспроизведение: Играет в приложении
- Состояние без настройки: Подключён

**Подключение**

- Нажмите «Найти музыку на телефоне» и разрешите доступ к аудио.
- Либо добавьте отдельные файлы вручную.

**Ограничения**

- ISRC, метка цензуры и текст берутся только из тегов файла.
- Если тегов нет, используется имя файла.

**Не подтверждено**

- Поддержка отдельных форматов зависит от устройства.

## Свой медиасервер

Ваша собственная коллекция на своём сервере: полные треки, FLAC, плейлисты и офлайн.

- Категория: Ваш сервер
- Воспроизведение: Играет в приложении
- Состояние без настройки: Нужна настройка
- Документация: https://opensubsonic.github.io/docs/

**Подключение**

- Укажите адрес сервера.
- Введите API-ключ либо логин и пароль.
- Нажмите «Проверить подключение».

**Ограничения**

- Нужен запущенный сервер, например Navidrome.
- При обычном http логин защищён слабо: для доступа через интернет используйте https.

**Не подтверждено**

- ISRC, метка цензуры и тексты появляются, только если их отдаёт ваш сервер.
- На реальном Navidrome интеграция ещё не проверялась.

## Audius

Независимая платформа: полные треки играют прямо в приложении.

- Категория: Независимые платформы
- Воспроизведение: Играет в приложении
- Состояние без настройки: Подключён
- Документация: https://docs.audius.co

**Подключение**

- Ничего вводить не нужно. Ключ можно создать на api.audius.co/plans и указать здесь.

**Ограничения**

- Часть треков закрыта условиями автора, они помечаются и не попадают в волну.
- Качество потока сервис не сообщает, показываем только формат MP3.
- Сохранение для офлайна не включено.

**Не подтверждено**

- Поля ISRC и parental_warning_type есть в ответе API, но авторы заполняют их редко.
- Доступность из России нужно проверить на телефоне.

## Jamendo

Каталог независимой музыки под лицензиями Creative Commons, полные треки в приложении.

- Категория: Открытые каталоги
- Воспроизведение: Играет в приложении
- Состояние без настройки: Нужна настройка
- Документация: https://developer.jamendo.com/v3.0

**Подключение**

- Откройте devportal.jamendo.com и зарегистрируйтесь.
- Примите условия API и создайте приложение.
- Скопируйте Client ID и вставьте его сюда.

**Ограничения**

- Только некоммерческое использование. Если приложение станет платным, нужен договор с Jamendo.
- 35 000 запросов в месяц на ключ.
- Лицензия показывается у каждого трека. Офлайн выключен.
- Сервис не сообщает, есть ли в треке цензура.

**Не подтверждено**

- Условия о кэшировании известны из вторичных источников.
- Точный битрейт режима mp32 документация не называет.
- Доступность из России нужно проверить на телефоне.

## Internet Archive

Концерты Live Music Archive, нетлейблы и оцифровки пластинок. Часто есть FLAC.

- Категория: Открытые каталоги
- Воспроизведение: Играет в приложении
- Состояние без настройки: Подключён
- Документация: https://archive.org/developers

**Подключение**

- Ничего настраивать не нужно.

**Ограничения**

- Качество и полнота описаний зависят от того, кто загрузил запись.
- Некоторые концерты разрешено только слушать онлайн, скачивание для них отключено.
- Live Music Archive предназначен для некоммерческого использования.
- ISRC и метки цензуры архив не содержит.

**Не подтверждено**

- Официальных лимитов запросов нет: при ответе 429 приложение ждёт.
- Доступность из России нужно проверить на телефоне.

## Spotify

Импорт ваших плейлистов и лайков с ISRC. Песни открываются в официальном приложении Spotify.

- Категория: Крупные сервисы
- Воспроизведение: Играет в своём приложении
- Состояние без настройки: Нужна настройка
- Документация: https://developer.spotify.com/documentation/web-api

**Подключение**

- Откройте developer.spotify.com/dashboard и создайте приложение.
- Добавьте Redirect URI: kamerton://spotify-auth
- Скопируйте Client ID сюда и нажмите «Войти».

**Ограничения**

- Импорт работает. Управление приложением Spotify (App Remote) требует нативного SDK и в этой версии не включено.
- Владельцу приложения нужен Premium, доступ не более чем у 5 пользователей.
- Импортируются только ваши и совместные плейлисты.
- Spotify не работает в России с 2022 года, обход ограничений приложение не выполняет.
- Данные Spotify не используются в рекомендациях и не смешиваются со звуком других сервисов.

**Не подтверждено**

- На реальном аккаунте импорт ещё не проверялся.
- Правила режима разработки часто меняются.

## YouTube (клипы)

Показ официальных клипов в видимом плеере YouTube.

- Категория: Крупные сервисы
- Воспроизведение: Только видимый видеоплеер
- Состояние без настройки: Нужна настройка
- Документация: https://developers.google.com/youtube

**Подключение**

- В Google Cloud Console включите YouTube Data API v3.
- Создайте API-ключ и вставьте его сюда.

**Ограничения**

- Видео играет со своим звуком, наш плеер на это время ставится на паузу.
- При сворачивании клип останавливается.
- Плеер не меньше 200×200 точек, без элементов поверх него.

**Не подтверждено**

- Доступность YouTube в России ограничена.
- Работа встроенного плеера на телефоне ещё не проверялась.

## SoundCloud

Задел под официальный API. Сейчас доступен только переход к поиску.

- Категория: Крупные сервисы
- Воспроизведение: Воспроизведение не включено
- Состояние без настройки: Пока не подключается
- Документация: https://developers.soundcloud.com

**Подключение**

- Понадобятся Artist Pro, приложение на soundcloud.com/you/apps и свой сервер для обмена токенов.

**Ограничения**

- Для ключа нужна подписка Artist Pro.
- Обмен кода требует секрета, поэтому нужен сервер: в приложении секрет хранить нельзя.
- Лимит 15 000 запусков потока в сутки на приложение.

**Не подтверждено**

- Требование секрета для всех клиентов известно из сторонних отчётов.
- Условия использования перед подключением нужно прочитать отдельно.

- Категория: Крупные сервисы
- Воспроизведение: Играет в своём приложении

**Ограничения**

**Не подтверждено**

- Оплата программы из России и работа SDK с новыми версиями Apple Music не подтверждены.
