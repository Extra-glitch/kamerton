# Источники музыки

Файл создан автоматически из описаний адаптеров (`npm run docs`).

## На телефоне

Ваша музыка на телефоне: MP3, FLAC, Opus, M4A и другие форматы, которые поддерживает Android.

- Категория: На этом телефоне
- Воспроизведение: Играет в приложении
- Состояние без настройки: Подключён

**Подключение**

- Нажмите «Найти музыку на телефоне» и разрешите доступ к аудио.
- Либо добавьте отдельные файлы вручную.

**Ограничения**

- ISRC, метка цензуры и текст берутся только из тегов файла.
- Если тегов нет, используется имя файла.

**Не подтверждено**

- Поддержка отдельных форматов зависит от устройства.

## Свой медиасервер

Ваша собственная коллекция на своём сервере: полные треки, FLAC, плейлисты и офлайн.

- Категория: Ваш сервер
- Воспроизведение: Играет в приложении
- Состояние без настройки: Нужна настройка
- Документация: https://opensubsonic.github.io/docs/

**Подключение**

- Укажите адрес сервера.
- Введите API-ключ либо логин и пароль.
- Нажмите «Проверить подключение».

**Ограничения**

- Нужен запущенный сервер, например Navidrome.
- При обычном http логин защищён слабо: для доступа через интернет используйте https.

**Не подтверждено**

- ISRC, метка цензуры и тексты появляются, только если их отдаёт ваш сервер.
- На реальном Navidrome интеграция ещё не проверялась.

## Audius

Независимая платформа: полные треки играют прямо в приложении.

- Категория: Независимые платформы
- Воспроизведение: Играет в приложении
- Состояние без настройки: Подключён
- Документация: https://docs.audius.co

**Подключение**

- Ничего вводить не нужно. Ключ можно создать на api.audius.co/plans и указать здесь.

**Ограничения**

- Часть треков закрыта условиями автора, они помечаются и не попадают в волну.
- Качество потока сервис не сообщает, показываем только формат MP3.
- Сохранение для офлайна не включено.

**Не подтверждено**

- Поля ISRC и parental_warning_type есть в ответе API, но авторы заполняют их редко.
- Доступность из России нужно проверить на телефоне.

## Jamendo

Каталог независимой музыки под лицензиями Creative Commons, полные треки в приложении.

- Категория: Открытые каталоги
- Воспроизведение: Играет в приложении
- Состояние без настройки: Нужна настройка
- Документация: https://developer.jamendo.com/v3.0

**Подключение**

- Откройте devportal.jamendo.com и зарегистрируйтесь.
- Примите условия API и создайте приложение.
- Скопируйте Client ID и вставьте его сюда.

**Ограничения**

- Только некоммерческое использование. Если приложение станет платным, нужен договор с Jamendo.
- 35 000 запросов в месяц на ключ.
- Лицензия показывается у каждого трека. Офлайн выключен.
- Сервис не сообщает, есть ли в треке цензура.

**Не подтверждено**

- Условия о кэшировании известны из вторичных источников.
- Точный битрейт режима mp32 документация не называет.
- Доступность из России нужно проверить на телефоне.

## Openverse

Музыка под свободными лицензиями из многих открытых каталогов сразу: Jamendo, Wikimedia Commons, ccMixter и другие. Играет целиком, в фоне и сохраняется на телефон.

- Категория: Открытые каталоги
- Воспроизведение: Играет в приложении
- Состояние без настройки: Подключён
- Документация: https://api.openverse.org/v1/

**Подключение**

- Ничего настраивать не нужно.

**Ограничения**

- Здесь в основном независимые музыканты: популярных песен крупных лейблов нет.
- Без регистрации: до 20 результатов за запрос и ограничение частоты запросов.
- Некоторые лицензии запрещают коммерческое использование. Для прослушивания и личной копии это не мешает.

**Не подтверждено**

- Работа из России без VPN не проверена.

**Подключение**

## Deezer

Большой каталог для поиска, включая российских исполнителей: обложки, альбомы и 30-секундные фрагменты.

- Категория: Крупные сервисы
- Воспроизведение: Только фрагменты
- Состояние без настройки: Подключён
- Документация: https://developers.deezer.com/api

**Подключение**

- Ничего настраивать не нужно.

**Ограничения**

- Только фрагменты по 30 секунд: полные треки Deezer сторонним приложениям не отдаёт.
- Фрагменты не сохраняются и не попадают в волну и историю прослушиваний.
- Полностью песню можно открыть в Яндекс Музыке, VK или Звуке кнопкой в меню трека.
- Разрешено некоммерческое использование с указанием Deezer.

**Не подтверждено**

- Работа API из России без VPN не проверена: проверка шла из сети GitHub.
- Условия Deezer об использовании метаданных в рекомендациях не проверены. Используется только имя исполнителя и год.

- Воспроизведение: Без воспроизведения
- Состояние без настройки: Подключён
- Документация: https://performance-partners.apple.com/search-api

**Подключение**

- Ничего настраивать не нужно.

**Ограничения**

- Подписка Apple Music в России работает, но оплатить её российской картой нельзя.
- Около 20 запросов в минуту: поиск Apple кэшируется.

**Не подтверждено**

- Доступность из России без VPN не проверена.

## YouTube

Поиск песен и клипов на YouTube и прослушивание целиком во встроенном плеере YouTube. Песни, найденные в каталоге Deezer или Apple, тоже играют целиком: их полная версия ищется на YouTube при нажатии.

- Категория: Крупные сервисы
- Воспроизведение: Только видимый видеоплеер
- Состояние без настройки: Нужна настройка
- Документация: https://developers.google.com/youtube/iframe_api_reference

**Подключение**

- Откройте console.cloud.google.com и войдите в аккаунт Google (нужен VPN).
- Создайте проект: вверху «Select a project» → «New project» → любое имя → «Create».
- Откройте «APIs & Services» → «Library», найдите «YouTube Data API v3» и нажмите «Enable».
- Откройте «APIs & Services» → «Credentials» → «Create credentials» → «API key».
- В настройках ключа в «API restrictions» выберите «Restrict key» и отметьте только YouTube Data API v3.
- Скопируйте ключ и вставьте его сюда. Ключ хранится только на телефоне в защищённом хранилище.

**Ограничения**

- В России YouTube заблокирован: без VPN плеер не загрузится. VPN в приложение не встроен.
- Видео играет со своим звуком, плеер Камертона на это время ставится на паузу.
- По правилам YouTube плеер должен быть виден: при сворачивании видео останавливается, фона и экрана блокировки нет.
- Скачивать видео и звук с YouTube правила запрещают, поэтому сохранения на телефон нет.
- Бесплатный ключ даёт около 100 поисков в сутки. Поиск полной версии для песни из каталога тоже тратит один поиск, но только в первый раз: найденное запоминается.

**Не подтверждено**

- Работа встроенного плеера на телефоне не проверена.

## SoundCloud

Поиск по SoundCloud и прослушивание целиком прямо в плеере Камертона, в том числе в фоне.

- Категория: Независимые платформы
- Воспроизведение: Играет в приложении
- Состояние без настройки: Нужна настройка
- Документация: https://developers.soundcloud.com/docs/api

**Подключение**

- Оформите подписку Artist Pro в SoundCloud (нужен VPN).
- Откройте developers.soundcloud.com/docs/api/register-app и зарегистрируйте приложение.
- Скопируйте Client ID и Client Secret сюда и нажмите «Проверить».

**Ограничения**

- Ключ API SoundCloud выдаёт только владельцам платной подписки Artist Pro.
- В России SoundCloud заблокирован: без VPN поиск и звук не загрузятся.
- Часть треков SoundCloud отдаёт только фрагментом или не отдаёт в вашем регионе: так и будет подписано.
- Без ключа работают только ссылки, они открываются во встроенном плеере SoundCloud.

**Не подтверждено**

- На настоящем ключе Artist Pro поиск и звук ещё не проверялись.

## Spotify

Импорт ваших плейлистов и лайков с ISRC. Песни открываются в официальном приложении Spotify.

- Категория: Крупные сервисы
- Воспроизведение: Играет в своём приложении
- Состояние без настройки: Нужна настройка
- Документация: https://developer.spotify.com/documentation/web-api

**Подключение**

- Откройте developer.spotify.com/dashboard и создайте приложение.
- Добавьте Redirect URI: kamerton://spotify-auth
- Скопируйте Client ID сюда и нажмите «Войти».

**Ограничения**

- Импорт работает. Управление приложением Spotify (App Remote) требует нативного SDK и в этой версии не включено.
- Владельцу приложения нужен Premium, доступ не более чем у 5 пользователей.
- Импортируются только ваши и совместные плейлисты.
- Spotify не работает в России с 2022 года, обход ограничений приложение не выполняет.
- Данные Spotify не используются в рекомендациях и не смешиваются со звуком других сервисов.

**Не подтверждено**

- На реальном аккаунте импорт ещё не проверялся.
- Правила режима разработки часто меняются.
