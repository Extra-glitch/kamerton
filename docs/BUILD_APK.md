# Сборка APK через GitHub Actions

Сборка идёт на серверах GitHub. Компьютер и Android Studio не нужны.
Названия кнопок на сайте GitHub могут немного отличаться.

## Что получается

- **Debug APK**: устанавливается без настройки подписи и без компьютера. Код приложения находится внутри файла.
- Файл называется `Kamerton-debug-НОМЕР.apk` и хранится **7 дней**. Он больше обычной версии, потому что содержит отладочные библиотеки.
- Сборка считается успешной только после проверки файла и запуска на эмуляторе Android. Подробности в разделе **Summary** запуска.

## Запуск с телефона

1. Откройте в браузере `github.com/ВАШ_ЛОГИН/kamerton` и войдите в аккаунт.
2. Откройте вкладку **Actions**. Если вкладок не видно, включите в меню браузера «Версия для ПК».
3. Слева или в списке выберите **Сборка APK**.
4. Нажмите **Run workflow**, затем зелёную кнопку **Run workflow**.
5. Обновите страницу. Появится запуск с жёлтым значком. Обычно сборка занимает 30–60 минут, страницу можно закрыть.

Сборка также запускается сама после каждого изменения кода в ветке `main`.

## Скачивание и установка на телефоне

1. Откройте завершённый запуск с зелёной галочкой.
2. Внизу страницы найдите раздел **Artifacts**.
3. Нажмите на `Kamerton-debug-НОМЕР.apk`. Файл скачается сразу как APK, без архива.
4. Откройте файл из уведомления браузера или из папки «Загрузки».
5. Если Android спросит, разрешите установку из этого браузера и вернитесь назад.
6. Нажмите **Установить**.

Google Play Защита может предупредить о неизвестном приложении, потому что файл собран вами. Обновление ставится поверх прежней версии, данные сохраняются.

## Если что-то пошло не так

- **Красный значок**: откройте запуск, затем красный шаг, и пришлите мне текст ошибки.
- **Шаг эмулятора красный, а APK в Artifacts есть**: файл собран, но автоматическая проверка нашла проблему. Отчёт лежит в `emulator-report-НОМЕР`.
- **Нет раздела Artifacts**: сборка ещё идёт, завершилась ошибкой или прошло больше 7 дней.
- **Старый 32-битный телефон**: при запуске выберите вариант с `armeabi-v7a`.

У приватных репозиториев бесплатный объём минут и хранилища GitHub ограничен тарифом. В публичных репозиториях стандартные сборки бесплатны, но код будет виден всем.
