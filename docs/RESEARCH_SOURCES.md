# Новые источники музыки: что проверено (19.11.2026)

## Telegram-боты

| | @TgSoundBot | @smusic2bot |
|---|---|---|
| Что о себе пишет | «Music Bot»: поиск, скачивание и прослушивание музыки в Telegram | «Музыка • Скачать видео • Поиск музыки»: скачивание видео с YouTube, TikTok, Instagram, Rutube, VK, Shazam |
| Как ищет | Внутри бота, по тексту. Откуда берёт файлы, бот не сообщает | Скачивает с перечисленных площадок |
| Полный аудиофайл | Да, присылает файл в чат | Да |

| Общение бот-с-ботом | Telegram разрешил его 7 мая 2026, но только если сам бот включил этот режим. Включён ли он у этих ботов — неизвестно | То же |
| Можно ли использовать файлы в другом приложении | Прав на музыку боты не подтверждают; файлы скачаны с чужих площадок | То же |

**Вывод.** Подключать ботов к Камертону напрямую нельзя: официального доступа нет, а автоматическое скачивание из них — это то же самое, что подключение к источнику без лицензии.
Сделано другое: любой аудиофайл, который у вас уже есть в Telegram, отправляется в Камертон через «Поделиться» (или сохраняется в память телефона и подхватывается сам).
